# Python Mini Projects

This repository contains three small Python projects I built to practice and improve my programming skills. Each project demonstrates basic concepts like functions, user input, loops, and file handling.

---

## 📌 Projects

### 1. 🧮 Calculator
- A simple calculator that can perform basic operations: addition, subtraction, multiplication, and division.
- Shows how to handle user input and implement functions in Python.

**Run it:**

cd calculator
python3 calculator.py

### 2. 📇 Contact list
- A program to manage contacts.
- Features include:
  -Add new contact
  -Search new contact
  -Delete new contact

**Run it:**

cd contact-list
python3 contact-list.py

### 3. Guess Game 
- A text-based game that demonstrates loops, conditionals and random response generation.

**Run it:**

cd game
python3 game.py
